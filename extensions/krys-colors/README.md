# VSCode theme extension "Krys Colors"

This theme's colors are originally based on the original Monokai.

Following _languages_ have been tested:

- Bash / Shell (*.{bash,sh})
- CSS
- Dockerfile
- Gettext (*.{po,pot})
- GDScript
- HTML
- Ignore (.gitignore)
- INI
- JavaScript
- Jinja2
- JSON
- Markdown
- Python
- React (*.{jsx,tsx})
- RegEx
- ReStructuredText
- Rust
- SQL
- TOML
- TypeScript
- XML
- YAML

## Grammars

This extension also includes some grammar overrides for better styling.
You can find those overrides in the `syntaxes` directory.

## Installation

The extension is available from the following marketplaces:
