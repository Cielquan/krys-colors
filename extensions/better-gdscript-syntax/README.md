# VSCode extension for GDScript syntax

This extention supports Godot >= 4 / GDScript >= 2. Old syntax is not supported.

## Installation

The extension is available from the following marketplaces:

- [VSCode Marketplace](https://marketplace.visualstudio.com/items?itemName=cielquan.better-gdscript-syntax)
- [Open VSX Marketplace](https://open-vsx.org/extension/cielquan/better-gdscript-syntax)
